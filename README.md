# RoboRace

Гонка программируемых роботов: пять команд на раунд, общий порядок фаз арены и 33 маршрута на 11 полях.

## Запуск

Нужны Node.js 20+ и соседняя папка `meme-police-sandbox`.

```powershell
cd roborace-web
npm ci
npm start
```

Откройте [игру](http://localhost:8090/bg/roborace?name=Player#race). Часть после `#` задаёт комнату. Второму игроку нужно отдельное приватное окно или другой адрес (`127.0.0.1` вместо `localhost`).

Для другого порта: `npm start -- --port 8092`. `npm run dev` включает перезапуск при изменениях серверного кода. Комнаты сохраняет песочница.

## Поля и графика

- `data/fields.js` содержит полную геометрию 11 полей и по три маршрута. `data/catalog.js` подключает их к игре; `data/start.js` задаёт начальное наполнение стартовой площадки в редакторе. Поддерживаются 2–8 участников; рекомендуемый состав используется для фильтрации маршрутов.
- `public/arena-art.js` рисует панели пола, ленты, поворотные платформы, ремонт, ямы, стены и устройства из SVG-примитивов.
- `npm run assets:build` воспроизводимо создаёт WebP полных полей 12×16, миниатюры, инструменты редактора и иллюстрации справочника.
- [Проверки проекта](docs/TESTING.md).

Геометрия служит источником данных для графики и механики. Стандартные арены загружаются как готовые WebP; поверх отображаются лазеры и игровые маркеры. Произвольные поля рисует тот же графический модуль с кэшированием результата по геометрии.

При загрузке серверного модуля проверяются контрольные суммы геометрии, исходников генератора и готовой графики. Если изображения устарели, отсутствуют или повреждены, запуск останавливается с сообщением об ошибке. Выполните `npm run assets:build` и перезапустите сервер. Изменение названий и маршрутов пересборки изображений не требует.

## Выбор поля и маршрута

В лобби доступны все 11 полей и 33 маршрута. Выберите поле, затем маршрут А, Б или В. Есть поиск по названию поля или маршрута, фильтр сложности и «Для нашего состава». Фильтры не меняют уже выбранный курс. Хост задаёт курс для комнаты, остальные участники могут осматривать поля и маршруты.

В списке используются миниатюры 300×400; полное изображение выбранного поля 1440×1920 загружается отдельно. URL картинки содержит хеш её содержимого для браузерного кэша.

## Игровой интерфейс

Личная панель содержит регистры с текстовыми названиями команд и карты руки. Общие регистры находятся в списке игроков; на телефоне список открывается кнопкой «Игроки». Масштаб поля стабилен между фазами игры.

Для возрождения выберите подсвеченную клетку и направление стрелкой рядом с роботом, затем нажмите «Возродиться». Допустимые клетки и направления определяет сервер с учётом стен и соседних роботов. Поддерживаются мышь, касание и клавиатура.

## Редактор и сохранения

Редактор поддерживает рисование конвейеров маршрутами, изменение остальных элементов, повороты основы и вида, отмену/повтор, экспорт и импорт. Восемь стартовых позиций фиксированы. Стены вокруг них можно редактировать.

Каталог и экспорт редактора используют общий формат `roborace-field`, версия 1. Каждый документ содержит полную геометрию 12×16, включая старт. Описание — в [формате полей](docs/FIELDS.md). Сохранения комнат имеют формат `roborace-room`, версия 1.

Партии сохраняют выбранные поле и маршрут при перезапуске, включая поля редактора.

## Проверки

```powershell
npm test
npm run test:fields
npm run test:browser
npm run test:persistence
```

`npm test` запускает быстрые проверки механики, данных и целостности ассетов. Длительные проверки геометрии и маршрутов запускаются через `test:fields`. Все группы вместе — `npm run test:all`. Браузерные проверки требуют установленного Chrome; пути задаются через `ROBORACE_BROWSER_PATH` и `MEME_POLICE_SANDBOX_DIR`.

`test:persistence` проверяет сохранение приватной программы и паузы при реальном перезапуске и удаляет временный дамп. Результаты поиска программ записываются в игнорируемую папку `artifacts`. Для снимков браузера задайте `$env:ROBORACE_SCREENSHOTS='1'`.

## Состав репозитория

В Git входят код, геометрия, тесты, документация, `package.json`, `package-lock.json` и файлы в `public/assets`. Готовые WebP позволяют запускать игру после `npm ci` без пересборки графики. Миниатюры загружаются по мере появления в списке. SVG полей существуют только в памяти генератора.

Зависимости, снимки браузера, результаты проверок, кэши, локальные дампы и настройки `.env` исключены через `.gitignore`.
