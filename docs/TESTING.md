# Проверки

| Команда | Назначение |
|---|---|
| `npm test` | Быстрые проверки механики, каталога, редактора, сохранений и целостности ассетов |
| `npm run test:fields` | Связность полей, транспортные ловушки и прохождение маршрутов со всех стартов |
| `npm run test:browser` | Игровые сценарии и вёрстка в Chrome |
| `npm run test:persistence` | Восстановление партии после перезапуска сервера |
| `npm run test:all` | Все группы последовательно |

Браузерные сценарии используют `meme-police-sandbox` и установленный Chrome. Пути можно задать через `MEME_POLICE_SANDBOX_DIR` и `ROBORACE_BROWSER_PATH`.

Для снимков интерфейса задайте `$env:ROBORACE_SCREENSHOTS='1'`. Снимки сохраняются в игнорируемой папке `artifacts`; они предназначены для ручного просмотра и автоматически с эталоном не сравниваются.

## Механика и данные

Проверяются команды, столкновения, фазы поля, повреждения, блокировка регистров, перезагрузка, возрождение и победа. Отдельные сценарии проверяют права ведущего, скрытые карты, таймер, паузу, историю и сериализацию. Проверка перезапуска использует временный дамп и удаляет его после завершения.

При загрузке серверного модуля проверяются SHA-256 геометрии, зависимостей генератора и готовой графики по `public/assets/manifest.json`. Несовпадение или отсутствие файла останавливает запуск с командой пересборки. `test/assets.js` дополнительно проверяет комплектность, размеры графики, локальные зависимости SVG и отказ запуска с устаревшими или повреждёнными изображениями. После изменения геометрии, материала или генератора выполните `npm run assets:build`. Проверки не выполняются в браузере или при игровых событиях.

## Поля и маршруты

`test/fields.js` проверяет связность пола, отсутствие одноклеточных тупиков и возможность добраться до безопасных обычных клеток с учётом фаз поля и вернуться на старт. Число обязательных пересечений механизмов используется как эвристика сложности маршрутов.

`test/routes.js` ищет безопасные программы через настоящий движок для каждого маршрута и стартовой позиции. Поиск предполагает доступность нужных команд и не моделирует случайную раздачу. В сценариях исполнения полных раундов на 2, 4 и 8 участников соперники неподвижны и находятся в перезагрузке: эти проверки выявляют ошибки исполнения и сохранения, но не оценивают соревновательный баланс. Результаты записываются в `artifacts/field-checks.json` и `artifacts/routes.json`.

## Браузер

Проверяются выбор поля и маршрута, фильтры, права хоста, импорт и экспорт редактора, программирование, таймер, перезагрузка, пауза, история и возрождение. Проверки вёрстки выявляют перекрытия, обрезанный текст, недоступные кнопки и изменение размеров поля между фазами.

`field-format` проверяет одинаковое чтение документов в браузере и Node.js, JSON-цикл полей каталога, сохранность всей геометрии и связей через стык. Проверки редактора охватывают импорт, экспорт, изменения старта, появление роботов по сохранённым координатам и независимость партии от заготовок редактора.

Учебные сцены конвейеров и коллизий сопоставляются с результатами движения игрового движка. Проверяются работа паузы, продолжения и повтора, клавиатурный фокус и режим уменьшенной анимации.
