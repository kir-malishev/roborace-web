# Формат поля

Каталог и экспорт редактора используют один документ: `format: "roborace-field"`, `version: 1`. Обработчик `public/field-format.js` общий для браузера и сервера.

Каждый документ содержит:

- `name` — название поля.
- `features` — полную геометрию 12×16, включая стартовую площадку.
- `routes` — маршруты отдельно от геометрии. У каждого есть `name` и упорядоченный массив `flags`; дополнительно допустимы `difficulty`, `recommendedMin`, `recommendedMax`.
- Необязательный `id` — уникальный идентификатор встроенного поля и его графики.
- Необязательный `rotation` — угол основы в редакторе. Координаты и направления элементов соответствуют этому повороту.

Координаты начинаются с нуля: основа занимает строки 0–11, старт — 12–15. Все координаты принадлежат общему полю, в том числе связи конвейеров через стык.

Свойства `features`:

- `starts`: восемь уникальных позиций `{x,y}` на строках 12–15 в порядке нумерации. Редактор защищает эти клетки от изменения.
- `pits`, `repairs`, `express`: массивы клеток `"x,y"`.
- `gears`: клетка → `1` по часовой стрелке или `-1` против.
- `conveyors`: клетка → направление выхода: `north`, `east`, `south`, `west`.
- `conveyorConnections`: направленные связи соседних лент, например `"8,9|8,8"`. При пустом массиве поворотных соединений нет; чтение файла не добавляет их автоматически.
- `hintConnections`: дополнительные соединения для оформления, без влияния на поворот робота.
- `walls`: края клеток, например `"5,6,east"`.
- `lasers`: объекты `{x,y,direction,count}`, где `count` — от 1 до 3.
- `pushers`: объекты `{x,y,direction,active}`, где `active` — номера регистров от 1 до 5.

Данные представлены массивами и объектами JSON. При подготовке к игре движок преобразует списки клеток в множества. Позиции появления роботов берутся из `starts`. Проверка добавляет монтажные стены устройств и удаляет стены внутри единой ямы.

Каталог содержит по три рекомендованных маршрута для каждого поля. Редактор работает с одним набором флагов: при импорте использует первый маршрут, при экспорте записывает текущий.

Для добавления поля вставьте экспортированный объект в массив `FIELDS` в `data/fields.js`, назначьте уникальный строковый `id` и выполните `npm run assets:build` и проверки полей.
